# BODYMAKE CONTEST

女子ボディメイクコンテストを題材にした、ニコニコ生放送向けの90秒ランキングゲームです。Akashic Engineのランキングモードで動作します。

## ゲームルール

- 画面表示後、3秒カウントダウンで自動開始します。
- 1ターンは5秒、全18ターンです。
- プレイヤー1名と、個性の異なるAIライバル5名で競います。
- `FRONT`、`BACK`、`WALK`、`SMILE`から1つを選び、ターン中の好きなタイミングで押します。
- `FRONT`と`BACK`はスタイル審査、`WALK`はウォーク審査、`SMILE`は表現力審査に有利です。対応関係は審査員欄とアクションボタンに常時表示されます。
- おすすめ表示がONの場合、毎ターン、審査傾向・在席審査員・連続減点・COMBO効果から期待値の高いアクションを算出し、金色に発光させます。おすすめ以外も自由に選べます。
- 入力後はステージ上部に「アクション 相性／低得点要因 ＋獲得点」を短時間表示し、タイミング結果画像と合わせて得点理由を伝えます。
- 選んだアクションは3人の審査員へ同時に反映され、各審査員欄の加点表示で結果を伝えます。
- プレイヤー入力後は各審査員枠にタイミング判定と加点を2段表示し、審査員不在または未選択の場合は`MISS`を表示します。
- 入力直後、各審査ゲージへ加わった値を審査員欄とステージ上部へ表示します。
- 審査傾向、タイミング精度、コンボ、同じアクションの連続使用でアピール値が変わります。通常アクションは対応する審査傾向倍率が3審査すべての獲得値へ適用されます。
- タイミング判定は`BAD`、`NORMAL`、`GOOD`、`PERFECT`の4段階です。
- アピール倍率は全ステージ共通で、`BAD ×0.50`、`NORMAL ×0.75`、`GOOD ×1.00`、`PERFECT ×1.45`です。
- `BAD`では、そのアクション中にVOLTAGEは増えません。
- 審査傾向1位に対応するアクションはVOLTAGEも溜まりやすく、それ以外のアクションは溜まりにくくなります。審査傾向倍率は1位160%、2位120%、3位80%です。
- プレイヤーのVOLTAGE基礎獲得量は`NORMAL 9`、`GOOD 15`、`PERFECT 18`です。GOOD中心なら2回、高精度入力と審査員ボーナスを活かせば3回目のSPECIALを狙えます。
- `GOOD`か`PERFECT`を連続するとCOMBOが増え、それ以外では0に戻ります。3COMBOごとにカーソルが速くなり高判定帯が狭くなる一方、審査傾向1位に合うアクションだけは5COMBOごとにアピール倍率が5%ずつ、最大25%上昇します。現在のゲージ難度と傾向1位倍率はCOMBO欄へ常時表示されます。
- AIの行動内容と時刻は予告されず、実行したアクションに対応するキャラクターモーションで伝えます。
- 行動を終えた選手は暗くなり、未行動の選手と見分けられます。
- 審査員のゲージを最も多く削るとTOP、最後の一押しをするとLASTボーナスを獲得します。行動順によるFIRSTボーナスはありません。
- 同じアクションを連続使用すると、審査傾向にかかわらず2回目が25%、3回目以降が50%減衰します。選択前は次回の減衰率、選択後は実際に適用した減衰率をボタンへ表示します。
- VOLTAGEが100%になると通常の4択がSPECIALボタンへ切り替わります。
- 通常入力だけでも13ターン目までにSPECIALが保証されます。
- 強敵AIはVOLTAGEを溜めてSPECIALを使用します。ライバルとチャンピオンは、予選で各2回、準決勝・決勝で各3回発動します。全ステージで序盤・中盤・終盤の時間帯ごとに発動ターンが変化します。
- プレイヤー・AIを問わず、SPECIAL実行時は発動者を隠さない四隅の短いマーカーと小粒の光が現れ、専用バストアップ画像がカットインします。主人公は右側から入るピンク基調のPLAYER演出、相手は操作欄より上に収まる赤い警告調のOPPONENT演出です。同時発動時は主人公1枠と相手2枠を独立表示し、後から発動したキャラクターが先のカットインを上書きしません。
- 舞台・ランキング欄・結果画面の順位は、1〜6位で色分けしたメダル画像で表示されます。
- 右側ランキングには現在順位と通過圏内・圏外、通過ラインとの差を表示し、クリア順位の境界を金色の線で示します。
- 順位変動、通過圏への出入り、審査項目TOPの奪取・陥落は短いポップアップで通知します。PERFECT・TOP奪取・順位上昇が重なった場合は大型成功演出になります。
- 各審査員は暫定トップや接戦状況をコメントでほのめかします。
- 低めの評価ゲージを削り切ると審査員が退場し、次のターンに次Lvの審査員が入場します。
- 審査員ゲージの耐久係数は全ステージで決勝と同じ値に統一し、90秒間の交代頻度を同程度にしています。
- タイトル画面で選んだ予選・準決勝・決勝のいずれかを、全18ターン通してプレイします。
- クリア条件は予選・準決勝が2位以内、決勝が1位です。
- 毎ターン開始時にターン数とステージ名を中央表示し、プレイ中はステージ右上に次ターンまでのカウントダウンを表示します。
- 90秒終了時のスコアがニコ生ランキングへ登録されます。

ランキングの公平性を保つため、全プレイヤーが標準難易度の固定条件でプレイします。

## 操作

- 操作欄上部のタイミングゲージを見ながら、全体表示アイコン付き4ボタンをクリック／タップします。ボタン下の「▲PERFECTを狙っていずれかのアクションを選択」は上にあるボタンを示します。選択したボタンとタイミングカーソルは次ターンまで停止し、SPECIAL時は「▲PERFECTを狙ってSPECIALを選択」と専用ボタンのみ表示されます
- キーボード `1`〜`4`
- 5秒以内に選べなかった場合はMISSとなり、スコアとVOLTAGEは一切増えません

## 予選チュートリアル

- タイトル画面の予選カードにチェック欄と「現在 ON／現在 OFF」を表示し、チュートリアルモードの状態を確認しながら切り替えられます。選択はインスタンスストレージの`tutorialEnabled`へ保存され、次回ゲームへ引き継がれます。保存値がない場合はONです。
- 予選のTurn 1～10で実際のUIを発光させながら案内し、各テーマを2ターン（10秒）ずつ表示します。
- Turn 1～2は「1ターン5秒」「カーソルに合わせるとGOOD / PERFECTで高得点」を案内します。Turn 3～4は審査傾向と審査員を見たアクション選びを案内し、おすすめ表示がONの場合のみ候補を発光します。Turn 5～6は連続アクションの減点、Turn 7～8は審査員ゲージ・交代とTOP／LASTボーナスを2行で案内し、Turn 9～10は順位と通過条件を案内します。
- 連続減点の対象ボタンは正解候補の発光を使わず、固定表示の赤い警告枠・×印・「連続は減点」で示します。
- Turn 11から5項目の案内を終了して通常表示へ戻ります。SPECIALの初回補足だけはTurn 11以降にも表示される場合があります。準決勝・決勝にはチュートリアルを表示しません。
- チュートリアルを有効にした予選で初めてSPECIALボタンへ切り替わった時は、ボタンを発光させて「全審査員へ一気に大アピール」と案内します。Turn 1～10の説明中は既存説明を残したまま、ボタン内の短い補足だけを追加します。
- 視線誘導中の割り込みを防ぐため、Turn 1～10に予定された相手SPECIALはTurn 11以降へ延期します。得点やタイミング判定への救済補正は行いません。

## おすすめ表示

- タイトル画面の「おすすめ表示」でON/OFFを切り替えられます。選択はインスタンスストレージの`recommendationEnabled`へ保存され、次回ゲームへ引き継がれます。保存値がない場合はONです。
- OFFの場合はアクションボタンのおすすめ発光と操作欄のおすすめ表示を行いません。
- OFFでステージをクリアした場合に限り、結果発表時のランキング登録スコアへ予選+10,000pt、準決勝+20,000pt、決勝+50,000ptを加算します。プレイ中のスコアやステージ内順位、クリア判定には影響せず、結果画面に加算額を表示します。未クリア時は加算されません。

## 実装

- Akashic Engine sandbox-runtime 3
- ニコ生 `ranking` モード
- `g.game.vars.gameState.score` と `g.game.requestSaveScore()` によるスコア登録
- 主人公・チャンピオン・ライバル・モブ3名のアニメーション画像とバストアップ画像、匿名審査員シルエット、アクションアイコン、3ステージ背景、画像化したタイミングゲージ、BGM・結果MEを使用
- `image`以下の全画像は合計10MB以内
- ゲーム内テキストは、Google Fontsで公開されている `M PLUS Rounded 1c Medium` をビットマップフォント化して使用
- 1280×720、WebGL／Canvas対応

## キャラクターアニメーション素材

`image/characters` に、6キャラクター×6モーションの透過・軽量化済み横4コマスプライトシートを収録しています。ゲームでは待機中にIDLEをループし、各アクションとSPECIALの実行時に対応画像へ切り替えます。フレーム仕様は `image/characters/README.md` を参照してください。

各フレームは足元基準で整列しており、アニメーション中の不要な左右移動を抑えています。元画像から192×288 pxのゲーム用フレームを生成して等倍表示し、6人を等間隔に配置しています。背景と接する無彩色フリンジを段階的に除去し、腕と胴体の間や髪の隙間も透過する一方、歯・瞳・白い衣装は保持します。チャンピオンは白・濃紺・金のレギンス衣装、主人公はピンクの専用フレームと「▼ 操作キャラ」マーカーで識別できます。

## バストアップ・UI素材

- `image/portraits` に全6キャラクターの通常バストアップと、主人公・ライバル・チャンピオンのSPECIAL用カットインを収録しています。
- `image/ui/timing` に4判定の伸縮可能なゲージ帯、外枠、ダイヤ型カーソルを収録しています。各区間は全面を均一に着色し、PERFECTのみ明るい金色で強調しています。

## BGM・ME

`audio` にAkashic Engine用のOgg Vorbis／AAC音源を収録しています。BGM・MEには、音楽の卵（おんたま）が公開するフリー音源を利用規約の範囲でカット・音量調整・形式変換して使用しています。BGMはクラシックオーケストラ素材から選定しています。

- 予選BGM: シュトラウス1世「ラデツキー行進曲」オーケストラ版。明快な行進リズムで、入りやすく華やかな予選を表現
- 準決勝BGM: ベートーヴェン「交響曲第5番『運命』第4楽章（冒頭部）」オーケストラ版。力強く押し寄せる展開で、予選より高い緊張感を表現
- 決勝BGM: ビゼー「カルメン 第一幕への前奏曲」オーケストラ版。高速で華やかな主題により、最終ステージのショー性と競争感を強調
- 勝利ME: オリジナル曲「勝利のうた」の冒頭にある独立した勝利ジングル部分（約5.8秒）
- 敗北ME: オリジナル曲「ぜんめつ」の冒頭4秒を使用し、終端をフェードアウト

各BGMはゲーム開始前の3秒と90秒の競技時間を途中ループなしで覆う約94秒に調整しています。音量はBGM間で大きな差が出ないよう揃えています。選択したステージのBGMを再生し、ステージごとのクリア順位を満たせば勝利ME、それ以外なら敗北MEを再生します。

配布元: 音楽の卵（ https://ontama-m.com/ ）

## SE

操作や進行のフィードバックには、効果音ラボのフリー効果音を使用しています。素材はゲームへの組み込みが認められた利用規約に基づき、Akashic Engine用のOgg Vorbis／AACへ変換して `audio/se` に収録しています。

- PERFECT: 「きらきら輝く5」（透明感のある輝き。約1.8秒に調整）
- GOOD: 「キラッ1」（鉄琴の短い輝き）
- NORMAL: 「決定ボタンを押す34」（柔らかい決定音）
- BAD: 「キャンセル8」（中世RPGにも合う落ち着いた失敗音）
- MISS: 「涙のしずく」（深い響きのある失敗演出）
- VOLTAGE MAX: 「きらきら輝く6」（生演奏のハープ。約2.8秒に調整）
- 主人公SPECIAL: 「可愛く輝く2」（アイドルの決めポーズ向け）
- 相手SPECIAL: 「ヒーローの決めポーズ」＋「チリン（凛とした女性が登場）」（力強い決め音に上品な余韻を重ねた約2.4秒の専用ミックス）
- 審査員帰宅: 「革靴で歩く」（退場用に約1.25秒を切り出し）
- 審査員追加: 「体育館で歩く」（会場に響く部分を約1.25秒切り出し）
- ターン開始: 「タイトル表示」（爽やかな短いタイトル音）

配布元: 効果音ラボ（ https://soundeffect-lab.info/ ）
