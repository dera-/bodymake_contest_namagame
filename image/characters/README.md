# Character Animation Assets

ゲーム中で使用する、透過・軽量化済みの横4コマスプライトシートです。

| ディレクトリ | キャラクター | ゲーム内番号 |
| --- | --- | --- |
| `hero` | 主人公 | No.1 |
| `mob_blue` | モブ（青髪） | No.2 |
| `mob_green` | モブ（緑髪） | No.3 |
| `mob_purple` | モブ（紫髪） | No.4 |
| `rival` | ライバル | No.5 |
| `champion` | チャンピオン | No.6 |

各キャラクターに `idle.png`、`front.png`、`back.png`、`walk.png`、`smile.png`、`special.png` があります。

- シート寸法: 768×288 px
- フレーム寸法: 192×288 px
- フレーム数: 4（左から右）
- 背景: 透過アルファ
- 全36シートの合計容量: 約4.69 MB
- 待機時: 両腕を下ろしたニュートラル姿勢と呼吸動作
- 行動時: 選択アクションに対応するシートをワンショット再生
- 各フレームは足元の中心と床位置を基準に整列し、意図しない左右ブレを抑制
- ゲーム内では192×288 pxのフレームを等倍表示
- 主人公にはピンクの専用フレームと「▼ 操作キャラ」マーカーを表示
- 主人公の歯・瞳など、顔の小さな明色ディテールは透過処理から保護
- チャンピオンは白を基調に濃紺・金を配したフルレングスのレギンス衣装

高解像度版はゲームのスキャン対象外である `tmp/source_assets_original` に退避しています。そこから再作成する場合は `tools/Optimize-CharacterAssets.ps1` を使用します。変換時に市松模様の周期を判定して背景を除去し、顔の明色ディテールと白い衣装を維持したまま透過・縮小します。
